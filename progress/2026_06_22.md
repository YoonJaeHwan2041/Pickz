## Step 7 — 로그아웃 API (`POST /api/v1/auth/logout`)

### 흐름

```
쿠키에서 Refresh Token 추출 (없어도 로그아웃 진행)
→ DB에서 해시로 조회
→ 유효한 토큰이면 revoke()
→ 쿠키 maxAge=0으로 클라이언트 쿠키 삭제
```

- 쿠키가 없거나 이미 폐기된 토큰이어도 에러 없이 200 응답 (멱등성 보장)

### 수정된 파일

- [`domain/auth/service/AuthService.java`](../src/main/java/com/yoon/pickz/domain/auth/service/AuthService.java)
  - `logout(rawRefreshToken)` 추가 — DB에서 조회 후 유효하면 revoke()

- [`domain/auth/controller/AuthController.java`](../src/main/java/com/yoon/pickz/domain/auth/controller/AuthController.java)
  - `POST /api/v1/auth/logout` 추가
  - 응답 시 쿠키 maxAge=0으로 클라이언트 쿠키 만료 처리

- [`infra/security/SecurityConfig.java`](../src/main/java/com/yoon/pickz/infra/security/SecurityConfig.java)
  - `/api/v1/auth/logout` permitAll 추가

## Step 6 — 토큰 재발급 API (`POST /api/v1/auth/refresh`)

### 흐름

```
쿠키에서 Refresh Token 추출
→ JwtProvider로 서명 검증 (userId 파싱)
→ SHA-256 해싱 후 DB 조회
→ revoked_at IS NULL + 만료 안 됐는지 확인 (isValid())
→ User 상태 ACTIVE 확인
→ 기존 Refresh Token revoke()
→ 새 Access Token 발급 후 응답
```

### 수정된 파일

- [`domain/auth/entity/RefreshToken.java`](../src/main/java/com/yoon/pickz/domain/auth/entity/RefreshToken.java)
  - `revoke()` 추가 — revokedAt = now()

- [`domain/auth/repository/RefreshTokenRepository.java`](../src/main/java/com/yoon/pickz/domain/auth/repository/RefreshTokenRepository.java)
  - `findByTokenHash(String tokenHash)` 추가

- [`domain/auth/exception/AuthErrorCode.java`](../src/main/java/com/yoon/pickz/domain/auth/exception/AuthErrorCode.java)
  - `INVALID_REFRESH_TOKEN` 추가

- [`domain/auth/dto/AuthDto.java`](../src/main/java/com/yoon/pickz/domain/auth/dto/AuthDto.java)
  - `RefreshResponse(accessToken, accessTokenExpiresAt)` 추가

- [`domain/auth/service/AuthService.java`](../src/main/java/com/yoon/pickz/domain/auth/service/AuthService.java)
